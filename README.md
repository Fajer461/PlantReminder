# 🌱 PlantReminder

An iOS app that helps you keep track of your plants' watering schedule, so none of them get forgotten.

## Features
- View all your plants in one list, organized by room
- Track light condition and water amount needed for each plant
- Mark plants as watered with a simple tap
- Dynamic progress bar showing how many plants still need water today
- Add, edit, and delete plants (swipe to delete)
- "All Done" celebration screen when every plant is watered

## Built With
- Swift
- SwiftUI
- MVVM Architecture
